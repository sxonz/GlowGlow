# 탄막 패턴과 미리보기

설계 출처: https://www.notion.so/3d470549c5e381969c14e3fba69508a0

## 적용

덱의 기존 1~6번 에셋을 Basic Shot, Laser Shot, Spread Shot, Bomb, Electric Pulse, Overdrive로 교체한다.
파일 GUID와 저장용 카드 ID는 유지해 저장된 8장 덱을 보존한다. 새 탄막은 6종이므로
나머지 임시 2종을 유지한다. `GlowGlow/Install First Four Barrages`는 첫 4종 명세를 다시 설치하는
명시적인 메뉴이며 인스펙터에서 수정한 수치를 덮어쓰므로 필요할 때만 실행한다.

## 실행 구조

- WeaponDefinition.steps: 지연, 위치, 모양, 피해 여부, 크기 변화, 속도 및 각도 범위를 저장한다.
- BarrageSequence: 발사할 때 각 단계를 복사한다. delay는 공통 발사 시점 기준이다.
  총구·방향·커서 위치도 발사 순간 고정하며, 무기 슬롯을 바꿔도 이미 발사한 공격은 계속된다.
- BarrageShapeProjectile: line/circle/box를 표시한다. dealsDamage=false가 예고용 도형,
  true가 circlev2/boxv2에 해당한다. 투명도와 피해 판정은 별개다.
- ProjectileBase: 도형/탄환/타임라인을 유형별로 풀링하며 재시작과 경기 종료 시 정리한다.
- 1번 플레이어는 마우스 월드 좌표, 2번 키보드 플레이어는 상대 위치를 목표로 사용한다.
  목표는 경기장 안으로 제한한다.

## 이번 구현에서 정한 미확정 값

| 항목 | 적용한 기준 |
| --- | --- |
| Basic Shot | 탄속 11, 쿨타임 0.26초, 반경 0.13. 화면 밖으로 나가면 제거 |
| Laser Shot | 쿨타임 1초. 총구에서 방향 고정. 예고 1초 후 길이 20·높이 0.3의 본체를 0.5초 표시 |
| 예고선 size | 길이는 고정하고 얇은 선의 두께를 10%에서 200%까지 1초 동안 변경 |
| 레이저 피해 | 예고선은 무피해, 본체는 피해 있음. 원문의 box(dmg x)와 피격 범위 언급이 충돌해 게임에서 공격으로 동작하도록 해석. steps의 dealsDamage로 변경 가능 |
| 레이저 섬광 | 등장 후 0.12초 동안 실제 판정보다 15% 큰 흰색 표시. 충돌체는 커지지 않음 |
| Spread Shot | 0초 1발, 0.1초 ±10도 80% 2발, 0.2초 ±20도 50% 2발. 쿨타임 2초 |
| Bomb 위치 | 커서에서 원 예고 후 같은 위치에서 boxv2와 파편 발생. 총구에서 파편이 나오는 것으로 해석하지 않음 |
| Bomb 예고 | 원 지름은 기본 탄 지름의 300%, 투명도 25%. 폭발 시 제거 |
| Bomb 크기 | 1초 지연 후 0.3초 동안 100→120%, 이어 0.5초 동안 0%까지 축소 |
| Bomb 회전 | 폭발의 0.8초 동안 한 방향으로 360도 회전. 사인 이징으로 시작·끝에서 느리고 중간에서 빠르게 회전하며 피격 범위도 함께 회전 |
| Bomb 파편 | 고정한 조준 방향 기준 각 90도 구간에서 1발씩, 총 4발. 각도·속도 80~120%는 매 발사 무작위 |
| Bomb 피해 | 예고 원 무피해, 사각 폭발과 파편은 피해 있음. 쿨타임 3초 |

기존 3회 피격과 무적 규칙을 사용한다. 패턴의 초 단위 연출은 고정이며, 기존 강화 중
발사 간격·탄속·기본 탄 크기·레이저 사거리를 사용한다. 화면 밖까지 유지되는 탄의 수명 강화는
효과가 없다. 기존 Laser 프리팹 방식은 steps가 비어 있는 무기에서 계속 사용할 수 있다.

## 새 탄막

### Electric Pulse

기존 임시 5번 카드를 교체하며 카드 ID와 GUID를 유지한다. 쿨타임 2초, 플레이어 위치에서
반경 3까지 0.25초 동안 퍼지고 총 0.4초 동안 보이는 무피해 전기 파동이다. 피해 횟수와 피격 무적을 발생시키지 않는다. 한 대상당 효과를 한 번만 적용하며,
명중하면 0.55만큼 경기장 안에서 밀어내고 정확히 0.3초 동안 이동 속도를 75%로 만든다.
범위·쿨타임·넉백 거리는 첫 구현의 기본값이다. 감속은 중첩 곱셈 대신 강한 효과를 유지하고
지속 시간을 갱신한다. 걷기와 대시에 적용하고 일시정지 중에는 지속 시간이 흐르지 않는다.
재시작 시 넉백과 감속을 초기화한다.

### Overdrive

임시 6번 카드를 교체한다. 최대 5초간 이동 속도 150%, 보호막 3, 관성을 적용한다.
관성은 입력 속도로 0.22초 시정수의 지수 보간을 하며, 키를 놓거나 방향을 바꿀 때 미끄러진다.
몸의 충돌 반경에 붙인 6개 가시가 초당 240도로 회전하고 실제 삼각형 충돌체로 공격한다.
지속 접촉은 기존 피격 무적 시간(0.8초)이 끝난 뒤 다시 피해를 줄 수 있다.
총구를 숨기고 다른 탄막을 포함한 신규 발사를 차단한다. 이미 발사한 탄막은 유지한다.
보호막은 피해 3회를 흡수하며 마지막 보호막을 깨는 공격은 본체 체력에 넘기지 않는다.
무피해 Electric Pulse는 보호막을 깎지 않는다. 보호막 소진 또는 5초 만료 시 가시·보호막·관성을
제거하고 총구·기본 이동 속도를 복구한다. 다른 감속 효과는 그 효과의 남은 시간에 따른다.
재시작·경기 종료·미리보기 종료 때도 동일하게 정리한다. 쿨타임은 임시 기본값 10초이며,
발동 시점부터 계산한다. 보호막이 일찍 깨져도 쿨타임은 유지한다.

### 덱 미리보기 동작

BarragePreview는 실제 WeaponRuntime을 별도 Physics2D 씬에서 실행하고 RenderTexture로 표시한다.
미리보기 전용 31번 레이어는 표시 중에만 타이틀 카메라에서 제외하고 종료 시 원래 마스크를 복구한다.
선택 변경·자동 반복 시 해당 소유자의 탄환만 제거한다. 덱을 닫으면 미리보기 씬과 텍스처를 해제한다.
미리보기는 제목·재생 버튼·상태 안내 없이 화면만 표시한다. 일반 탄막은 두 표적을 8만큼,
전기 펄스는 효과가 닿는 외곽인 2.8만큼 떨어뜨려 배치한다. line 예고선에는 원형 글로우를 적용하지 않는다.
UI는 Title.unity에 저장되어 있으며 동작용 카메라·표적은 플레이 중 미리보기가 열릴 때 생성한다.

### 파라미터로 추가

WeaponDefinition에 steps를 추가하면 별도 동작 스크립트 없이 조합할 수 있다.
Bullet의 startSize는 기본 탄 대비 크기이고, Circle/Box의 dimensions는 기본 탄 지름 대비 배율이다.
Gun 위치의 Box는 레이저로 해석해 Range를 길이, dimensions.y를 월드 높이로 사용한다.
고정 도형에는 duration을 지정한다. duration=0은 화면 밖까지 이동하는 Bullet용이다.
offsetDegrees와 speedMultiplier의 최소·최댓값을 같게 두면 무작위 변화가 없다.
