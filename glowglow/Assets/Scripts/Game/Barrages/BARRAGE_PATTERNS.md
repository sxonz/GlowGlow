# 탄막 패턴과 업그레이드

## 실행 구조

- `WeaponDefinition`은 기본 속성과 패턴, 등급을 저장한다. `WeaponRuntime`은 장착 탄막별 쿨타임과 획득 업그레이드를 소유한다.
- `BarrageUpgradeDefinition`은 대상 탄막, 효과, 3개 중 표시 슬롯을 지정한다. `Resources/WeaponUpgrades`의 33개 에셋을 사용한다.
- `WeaponUpgradeState.Effects`가 획득 효과를 합치고, 수치 강화는 `BarrageUpgradeDefinition.ApplyStats`, 패턴 변화는 `WeaponPatternCompiler`가 처리한다.
- 발사 시 속성·효과·패턴을 복사한다. 강화나 슬롯 변경은 이미 발사한 공격을 바꾸지 않으며 원본 에셋과 다른 플레이어의 상태도 바꾸지 않는다.
- `ProjectileBase`가 수명, 풀링, 소유자, 피해 필터를 제공한다. `Bullet`, `Laser`, `Bouncer`, `OrbitOrb` 등 개별 클래스에서 동작을 확장한다.
- 탄과 UI 이미지는 준비된 PNG를 재사용한다. 펄스 등의 선 효과는 LineRenderer를 사용한다.

### 레이저와 스프레드 조준

레이저 예고선·본체·판정이 현재 총구 위치와 방향을 따라간다. 레이저 중 조준은 초당 최대 30도,
SmoothDampAngle 응답 시간 0.18초로 가감속한다. 기본 이동 배율은 65%다.
실제 레이저가 나갈 때 뒤로 0.9만큼 반동을 초당 12의 속도로 적용해 전진 입력 중에도 밀려난다. 종료 후 0.18초간 응답 시간 0.035초·
최대 초당 1440도로 빠르게 커서에 복귀한 뒤 일반 조준으로 전환한다.
본체 섬광은 0.22초간 표시하며 115% 크기를 총구 앞에 정렬해 뒤쪽으로 튀어나오지 않는다.

스프레드는 모든 지연 탄환이 발사되는 시점의 총구 위치와 방향을 읽고 각도 오프셋을 더한다.
지연 발사는 LateUpdate에서 처리하여 현재 프레임의 이동을 반영한다.

### 펄스·오버드라이브·오브 이동

펄스는 대상 중심 기준으로 범위를 판정한다. 밀어내기 거리는 범위 끝까지 남은 거리이며,
그 거리에 따라 초기 속도와 감쇠 시간을 정한다. 강한 충격일수록 초기 조작 비중을 줄이고
충격이 잦아들며 복구한다. 기존 0.3초간 이동 속도 75% 감속도 적용한다.
끌어당기기는 시전자와 양쪽 몸 반경이 닿는 위치에서 멈춘다.

오버드라이브는 직선 입력 유지 시 1.4초에 걸쳐 목표 속도를 기본의 최대 1.8배로 올린다.
회전·정지하면 직선 가속이 감소한다. 가속과 실제 속도에 비례하여 관성 응답 시간이
0.16~0.38초로 커진다. 보호막 소진·수명 종료 시 가시, 보호막, 가속, 관성을 정리한다.

오브의 공전 중심은 0.45초 SmoothDamp로 플레이어를 느슨하게 추종한다. 최대 뒤처짐 제한을 두지 않아 이동·대시 시 공전 중심이 뒤에 남았다가 따라온다.
12개 PNG 잔상은 지나간 월드 위치에 남고 0.3초 동안 옅어진다.

모두 최대 1회 획득한다. 아래 번호는 UI 파편 슬롯이며 선행 조건이나 획득 순서가 아니다.
현재 보유한 탄막의 미획득 업그레이드가 무작위로 등장한다.

| Basic Shot | 탄속 +20% | 탄환 크기 +20% | 쿨타임 -10% |
| Laser Shot | 예고 시간 -25% | 예고 중 이동 감속 제거 | 쿨타임 -15% |

| Bomb | 50% 확률로 무작위 위치에 연쇄 폭발 1회 | 파편 개수 +50% (4→6) | 예고 시간 -25% |
| Electric Pulse | 돌진 직후 범위 -50%, 밀치는 힘 +200%, 벽 충돌 피해 | 쿨타임 -15% | 끌어당기기로 전환, 이펙트도 수축 |

| Bouncer | 벽·지형에 튕길 때마다 수명 +0.3초 | 반사 방향에 -20~20도 무작위 편차 | 쿨타임 -10% |
| Orbit Orb | 첫 오브를 중심으로 공전하는 크기 50%인 두 번째 오브 (2-Axis) | 공전 속도 +50% | 수명 +50% |

### 조합 및 세부 기준

- 레이저 예고 감속 제거는 실제 빔의 감속·회전 제한·반동을 없애지 않는다. 예고 단축 시 본체 발사도 함께 당겨진다.
- 소형 탄환은 `Bullet` 계열 중 반경 0.16 이하로 판정한다. 오브는 크기와 관계없이 제외한다. 중앙탄의 요격은 발사마다 최대 1회다.
- 폭탄 연쇄는 경기장 안 무작위 위치에서 예고 → 폭발 + 파편을 한 번 더 재생한다. 전체 순서는 원본보다 0.35초 늦게 시작하며, 예고 시간 감소와 파편 증가 업그레이드도 동일하게 적용된다. 추가 연쇄는 발생하지 않는다.
- 돌진 강화 판정은 돌진 종료 0.25초 전부터 종료 후 0.35초까지다. 돌진 시작 전에는 발동하지 않으며, 기본 돌진 시간 0.16초에서는 돌진 중 전체가 포함된다. 밀치는 힘 +200%는 기본 거리의 3배로 적용하며 충격도 빠르게 전달한다. 강화 밀어내기는 경기장 벽 충돌 시 기존 피해 1회를 준다.
- 돌진 강화와 끌어당기기를 함께 획득하면 강화 발동 중 시전자와 접촉할 때 피해 1회를 준다. 일반 펄스·일반 끌어당기기는 무피해다. 기존 무적·보호막 규칙은 유지한다.
- 오버드라이브 가속 강화는 0.7초에 최대 목표 속도 2.6배로 상승한다. 관성 감소는 응답 시간을 35%로 줄인다.
- 바운서의 수명 연장에는 횟수 제한이 없다. 연장되어도 감속을 재시작하지 않고 3초 이후 탄속 12.75를 유지한다. 페이드는 실제 남은 수명을 사용한다. 적 명중 시에는 즉시 소멸한다.
- 2-Axis의 첫 오브는 플레이어의 지연된 공전 중심을 돌고, 두 번째 오브는 첫 오브 자체를 중심으로 반경 1.2·초당 360도로 돈다. 회전·수명 강화는 두 오브 모두 적용되며, 첫 오브가 사라지면 두 번째 오브도 정리된다.

## Meteor Dive (유니크)

도감의 9번째 카드이며 기존 기본 8장 덱은 유지한다. 덱의 카드 하나를 교체하거나 연습장에서 선택한다.
쿨타임은 사용 시점부터 10초다. 2초간 플레이어 본체·총구·발광·잔상과 몸 충돌체가 사라지고
이동·대시·신규 발사·피격을 차단한다. 예고선은 경기장 위에서 바닥까지 세로로 고정된다.
사용자의 기존 가로 위치에서 시작해 커서의 가로 좌표만 기본 이동 속도의 90%(기본 5.22)로 추적한다.
커서 세로 위치는 무시하며 착지 높이는 플레이어의 경기장 하단 이동 한계로 고정한다.
예고 중 왼쪽 마우스를 다시 클릭하면 현재 예고선 위치를 고정하고 즉시 낙하를 시작한다. 발동 클릭이나 누르고 있기는 조기 낙하를 일으키지 않는다. 클릭하지 않으면 2초 후 자동 낙하하며, 어느 경우든 바닥까지 0.2초 동안 가속 낙하한다. 낙하 중에는 본체가 다시 보이며,
몸 반경으로 이동 경로 전체를 검사해 적에게 피해를 준다. 대상당 낙하 피해는 1회다.
착지하면 반경 1.2 폭발이 0.45초간 줄어들고 작은 Bullet 계열 파편 12개가 위쪽 35~145도로 솟구친다.
파편 반경 0.065~0.1, 기본 초기 속도 5.5~9에 위쪽 속도 성분만 1.25배를 적용한다.
이전보다 상승 높이가 약 56% 증가한다. 중력 14, 수명 2.5초이며 마지막 0.35초에 페이드한다.
파편도 이동 경로 전체의 충돌을 검사해 적에게 피해를 주고 소멸하며, 기존 중앙탄 요격 대상에 포함된다.
낙하·폭발·파편은 기존 피격 무적 시간을 준수한다. 착지 즉시 일반 조작·몸 충돌·피격이 복구된다.
재시작·취소·경기 종료 시에도 원래 위치에서 복구한다. 효과와 임시 아이콘은 기존 PNG를 사용한다.
전용 업그레이드 3종도 각각 1회씩 순서 없이 무작위로 획득한다. 미니탱크 지원은 낙하 시작 시 좌우 1.5 간격에 각각 크기 50%의 미니탱크를 생성한다(벽에서는 경기장 안으로 제한). 각 미니탱크는 경로 피해, 반경 0.6 폭발, 크기 50% 파편 6개를 생성한다. 폭발 강도 50%는 범위로 적용하며 피격 피해는 기존 1회다. 빠른 예고는 예고선 추적 속도를 기존 대비 10% 증가시킨다(기본 이속의 90% → 99%). 낙하 보호막은 자동/조기 낙하 시작 시 보호막 1을 지급하고 착지 후에도 유지한다. 피해 1회를 막으면 사라지며 중첩 없이 1로 보충하고 재시작 시 초기화한다. 오버드라이브 보호막과는 별도이며 낙하 보호막을 먼저 소모한다.

## Octo Shot (커먼)

도감의 10번째 카드로 추가하며 기존 기본 8장 덱은 유지한다. 플레이어 중심에서 조준 방향을 기준으로
45도 간격의 탄환 8개를 동시에 발사한다. 초기 기준은 탄속 6, 수명 0.8초, 반경 0.13, 쿨타임 1.4초다.
마지막 0.15초에 페이드한다. 전용 업그레이드 3종은 독립적으로 무작위 획득한다.

- 속사 팔방탄: 탄속 +25%(7.5), 쿨타임 -15%(1.19초)를 함께 적용한다.
- 회전 탄도: 탄환 방향이 초당 60도로 휘어진다. 적분된 곡선 위치를 사용해 프레임별 오차를 줄인다.
- 잔탄 분열: 원본 수명 종료 시 진행 방향 ±20도로 작은 탄환 2개가 분열한다. 크기 50%, 수명 0.45초,
  속도와 곡선 효과는 유지한다. 재분열하지 않으며 명중·경기 종료·재시작에 의한 제거에서는 분열하지 않는다.
## Boomerang (레어)

도감의 11번째 카드다. 쿨타임 8초, 발사 탄속 14, 반경 0.432(기존보다 20% 증가).
발사 방향으로 1.1초 동안 탄속 14에서 0까지 일정하게 감속하며 7.7만큼 날아간다.
거의 멈추는 시점에 그 순간의 플레이어 위치를 향해 탄속 21로 즉시 복귀한다.
복귀 방향은 전환 시 한 번 정하며, 이후 플레이어가 피하면 해당 방향으로 계속 지나간다.
외형은 기존 Barrel PNG 두 개를 조합한 V자이며 초당 720도로 회전한다.
돌아오는 동안 소유자의 몸에 닿으면 회수되고, 발사했던 무기의 남은 쿨타임이 기본 2초 감소한다. 소유자가 사라져 있는 동안은 회수되지 않는다.
회수하지 못하면 발사 지점을 지나 뒤로 계속 이동하며, 경기장 밖 여유 공간을 벗어나면 정리된다. 벽에서 반사되지 않는다.
기본 상태에서도 적을 관통하며, 피격 무적 시간이 끝나면 다시 피해를 줄 수 있다. 경기 종료·재시작·미리보기 종료 시에는 정리된다.

- 회수 보상: 회수 시 쿨타임 감소량을 2배로 늘려 4초 줄인다. 슬롯 변경과 무관하며 최소 0초다.
- 대형 부메랑: 외형과 판정 크기 +15%.
- 반사 부메랑: 발사부터 복귀까지 합계 최대 2회 경기장 벽에서 반사한다. 속도를 유지하며, 이후에는 벽을 통과해 경기장 밖에서 정리된다. 모서리 동시 접촉은 1회로 센다.

확장된 강화 효과는 런타임에서 64비트 플래그를 사용한다. Unity 에셋에는 effectLow/effectHigh의
두 32비트 값으로 보존하며, 기존 effect 필드는 FormerlySerializedAs로 읽어 기존 강화 데이터를 유지한다.
## Prism Shot

레어, 쿨타임 5초. 왼쪽부터 1~7번인 탄환을 1·7 → 3·4·5 → 2·6 순서로
0.15초 간격으로 발사한다. 1·7은 느린 직선, 3·5는 4번 탄환을 중심으로 공전, 4는 직선,
2·6은 이중나선 궤적으로 이동한다.
발사 0.8초 후 거리 5 부근에서 60도 부채꼴을 형성한다. 3·5번은 4번의 좌우에 정렬된다.
3·4·5번은 동시에 발사되고, 발사 직후부터 3·5번의 공전 중심이 4번 궤적과 일치한다. 4번이 명중해 소멸해도 그 궤적을 따라 계속 공전한다.
이후 벽이나 적에 닿을 때까지 이동하며 이중나선과 공전 궤적도 계속 유지한다. 탄환 반경은 0.1이다.
두 곡선의 위상 속도는 형성 시간과 독립적인 초당 180도(한 주기 2초)다. 지연 발사되는 탄환은 현재 총구에서 출발한다.
각 탄환은 수명 제한 없이 이동하며, 벽·지형에 닿거나 적에게 명중하면 소멸한다. 전투 정리 시 지연 발사도 취소된다.
두 탄환이 공전하는 전용 PNG 아이콘을 사용한다.

- 빠른 재장전: 쿨타임 15% 감소(5초 → 4.25초).
- 꼬리 탄환: 0.45초에 3·4·5 궤적을 반복하고 0.6초에 4번을 한 번 더 발사한다. 총 11발.
  추가 탄환은 현재 총구에서 출발하며 원래 궤적을 시간·위치만 옮겨 재현한다.
- 착탄 폭발: 적 또는 벽·지형에 충돌하면 반경 0.6, 유지 0.25초의 피해 폭발을 생성한다.
  경기장 벽 충돌은 화면의 Arena Border를 기준으로 하며, 벽 접점이 원의 중심이다. 본체·섬광·잔광의 벽 밖 부분은 월드 좌표로 잘라낸다.
  취소·요격에는 폭발하지 않으며 폭발에서 추가 폭발이 이어지지 않는다.

발사 시작부터 마지막 탄환 발사까지 총구를 고정한다(기본 0.3초, 꼬리 강화 0.6초).
이후 초당 720도로 현재 커서 방향까지 회전하며, 전투 취소·초기화 시 고정 상태도 해제한다.

## 등급과 획득 표시

`WeaponRarity`: Common 흰색, Rare 파랑, Unique 보라, Legendary 주황.
탄막 자체의 효과 색은 `WeaponDefinition.color`로 별도 관리한다.
3개 PNG 파편 중 획득한 슬롯만 해당 카드 등급 색으로 칠하고 나머지는 회색으로 둔다.
현재 선택 카드와 전투 슬롯의 표시는 같은 `WeaponRuntime` 상태를 구독한다.

## 시작 선택

첫 라운드는 덱의 신규 탄막 3개 중 1개를 선택한다. 2·3라운드는 신규 탄막과
보유 탄막에 적용 가능한 미획득 업그레이드를 섞어 각각 3개를 제시한다.
가능한 경우 신규 탄막과 업그레이드를 적어도 하나씩 포함한다.
카드 뒤집기 완료 후 매 라운드 8초를 제공한다. 클릭/숫자 1~3으로 선택하고 버튼/Enter로 확정한다.
시간 초과 시 선택한 카드를 확정하며 선택이 없으면 무작위로 고른다.
3회 확정 후에만 전투와 전투 타이머를 시작한다. 강화 선택은 슬롯을 추가하지 않으므로
최종 장착 탄막은 1~3개이며 런타임을 그대로 넘겨 강화 상태를 보존한다.

## 검증

`Assets/Editor/CombatUpgradeChecks.cs`의 `GlowGlow/Validate Combat Upgrades` 메뉴로 검증한다.
저장된 씬을 연 상태에서 실행하며 검증용 추가 씬을 정리한 뒤 원래 씬으로 돌아온다.
별도 Unity 프로젝트의 배치 검증은 에셋 36개, 무작위 선택과 상태 보존, 수치·패턴 변화,
실제 컴포넌트의 요격·반동·펄스 충돌·보호막·오브·바운서 지형 반사를 검사한다.

`GlowGlow/Install First Four Barrages`, `Install Electric Pulse`, `Install Overdrive`는
기본 에셋을 다시 작성하는 명시적 설치 메뉴다. 인스펙터에서 수정한 수치를 덮어쓰므로 필요할 때만 실행한다.
