# Barrage-inspired UI

메인 화면의 배경·로고·버튼 디자인을 유지하며 나머지 화면을 탄막 아이콘과 같은
네온 선, 부드러운 발광, 궤도 기호, 잘린 모서리 프레임으로 통일했다.
보조 화면을 열 때 메인 로고와 설명만 숨기며 메인으로 돌아오면 복구한다.

## 적용 화면

- 싱글플레이어 / 멀티플레이어 모드 선택: 큰 제목과 전용 기호, 읽기 쉬운 메뉴 행.
- 설정: 소리·탄막 투명도·그래픽 테마 구획, 다이아몬드 슬라이더 손잡이와 선택 표시.
- 봇 설정: 난도 입력과 슬라이더, 프리셋, 유효성 피드백, 시작/돌아가기.
- 덱 도감: 큰 원본 탄막 아이콘, 선택 프레임, 도감/미리보기/현재 덱 구획.
- 온라인 로비: 랭크·친구방·코드 입력을 구분한 연결 화면.
- 시작 탄막 선택: 탄막별 색 프레임과 큰 아이콘, 선택 상태, 확정 버튼, 봇 선택 요약.
- 전투 HUD: 체력 게이지, 일관된 슬롯과 준비/재사용 표시.
- 전투 결과: 결과 카드와 클릭 가능한 다시 대전/나가기, 기존 R/ESC도 유지.
- 훈련장: 전용 콘솔, 아이콘 목록, 강화 조절부, 표적/리셋/피해 통계.

이름은 밝게 유지하고 등급과 탄막 색은 배지·아이콘·프레임으로 구분한다.
모달 내부의 배경은 불투명하게 처리해 이전 화면의 글자가 겹치지 않는다.

## 에셋과 비용

`Assets/Editor/NeonUIAuthoring.cs`의 **GlowGlow / Bake UI Theme**로 프레임과 기호 32개를
`Assets/Resources/UI/NeonUIAtlas.png` 한 장에 굽는다. 1024×512 RGBA32 GPU 텍셀은
2 MiB다. 밉맵과 런타임 CPU 읽기를 끄고 기존 Sprite ID는 다시 구울 때 보존한다.
프레임은 9-slice이며 발광도 PNG에 포함한다. 별도 UI 발광 재질이나 블러 패스는 없다.

`NeonUI.cs`는 이 에셋들을 한 번 로드해 캐시한다. 런타임 Sprite.Create나 텍스처
생성은 없고 UI를 만들거나 최초 표시할 때 Image를 구성한다. 같은 화면을 다시 열어도
장식이 누적되지 않는다. 장식은 레이아웃과 레이캐스트에서 제외한다.
호버/포커스는 기존 Selectable 색 전환을 이용하며 별도 프레임별 애니메이터를 추가하지 않는다.
전투 슬롯의 상태 캐시는 유지하고, 탄막 선택 타이머와 봇 요약은 표시 값이 바뀔 때만 갱신한다.
체력·피해·네트워크 메시지와 탄막 자체의 준비된 아이콘은 변경하지 않는다.

## 검증

격리 Unity 6000.0.68f1 프로젝트에 현재 Assets와 의존성을 복사한다.
다른 SmokeRunner.cs는 Assets 밖으로 옮기고 `UIThemeSmokeRunner.cs`만 복사한다.
`-batchmode -executeMethod UIThemeSmokeRunner.Begin -logFile <log>`로 실행한다.
렌더링을 위해 `-nographics`와 `-quit`는 사용하지 않는다.

실제 Title/Arena 씬에서 메뉴, 설정, 봇 입력, 도감 4페이지, 로비, 탄막 선택, 전투,
결과, 훈련장을 캡처한다. 글자 넘침, 슬롯/입력/강화 동작, 준비된 에셋 재사용과
워밍업 이후 슬롯 갱신의 할당량을 검사한다. 기본 1600×900 및 훈련장 1200×900,
1920×1080을 확인한다. 캡처와 보고서는
`Builds/ConstellationValidation/ValidationOutput/ui-*`에 저장한다.

## 검증 결과 — 2026-10-29

- UIThemeSmokeRunner: 28개 검사 통과. 실제 화면 17개 캡처에서 텍스트 넘침 0건.
- TrainingSmokeRunner: 전체 탄막/강화, 리셋, 표적, 훈련장 모드 분리 검증 통과.
- HealthDamageSmokeRunner: 체력/피해/동기화/HUD 115개 검사 통과.
- SingleplayerTwinSmokeRunner: 모드 스크롤과 키보드 탐색 등을 포함한 34개 검사 통과.
- 전투 슬롯 갱신은 워밍업 후 100회 호출에서 추가 할당 0바이트.
- 작업 폴더의 코드 97개와 UI 아틀라스·씬 해시가 검증 프로젝트와 일치함을 확인했다.

모음 이미지: `ui-theme-preview.png`. UI 검사 보고서: `ui-theme-validation-result.txt`.
원본 캡처에서 `Tools/BuildUIPreview.ps1`로 모음 이미지를 다시 만들 수 있다.
검증은 격리한 로컬 Unity 에디터에서 수행했으며 실제 두 PC의 Steam 통신은 포함하지 않는다.
